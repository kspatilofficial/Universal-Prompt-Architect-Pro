# Production Go-Live Checklist

**Project:** Universal Prompt Architect Pro (UPAP)

**Repository Version:** v1.0.0 RC1

**Repository Certification:** RC1.1

**Module:** 05_Deployment

**Status:** Production

---

# 1. Purpose

This checklist defines the final operational verification required before deploying Universal Prompt Architect Pro (UPAP) into a production Gemini environment.

Its purpose is to ensure that deployment proceeds using only certified repository assets and follows all governance, validation, and operational requirements.

This checklist should be completed before every production deployment.

---

# 2. Repository Verification

- [ ] Certified repository version selected.
- [ ] Repository certification verified.
- [ ] Repository structure unchanged.
- [ ] Required repository modules available.
- [ ] Repository documentation synchronized.

---

# 3. Knowledge Package Verification

Confirm:

- [ ] Approved knowledge package prepared.

- [ ] Upload sequence confirmed.
- [ ] No obsolete knowledge included.
- [ ] No duplicate knowledge included.

---

# 4. Prompt Verification

Confirm:

- [ ] Certified Production System Prompt selected.
- [ ] Prompt version verified.
- [ ] Prompt has not been modified.
- [ ] Prompt matches repository version.

# 5. Governance Verification

Confirm:

- [ ] Repository freeze respected.

- [ ] Documentation standards satisfied.

# 6. Validation Verification

Confirm:

- [ ] Validation completed.
- [ ] Acceptance Testing completed.
- [ ] Certification approved.
- [ ] Outstanding findings resolved or accepted.

---

# 7. Deployment Preparation

Confirm:

- [ ] Deployment platform identified.
- [ ] Deployment package prepared.
- [ ] Knowledge package attached.
- [ ] Repository version recorded.
- [ ] Deployment operator assigned.

# 8. Platform Verification

## Gemini Gem Manager

If applicable:

- [ ] System Prompt configured.
- [ ] Knowledge uploaded.
- [ ] Initial validation completed.

---

## Gemini Opal

If applicable:

- [ ] Workflow configured.

- [ ] Knowledge attached.
- [ ] Workflow validation completed.

---

# 9. Operational Readiness

Confirm:

- [ ] Rollback procedure available.
- [ ] Operational monitoring prepared.
- [ ] Maintenance responsibilities assigned.
- [ ] Deployment records prepared.

---

# 10. Go-Live Decision

Deployment may proceed only when:

- All applicable checklist items have been completed.
- Repository certification remains valid.
- Validation has passed.
- Deployment package is complete.
- Knowledge package is synchronized.
- Operational responsibilities are assigned.
