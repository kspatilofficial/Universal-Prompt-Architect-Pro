## Purpose
This guide is the compact handoff reference for the Universal Prompt Architect Pro Gem.

## What the project is
A governance-driven prompt engineering system designed to generate high-quality prompts, maintain domain knowledge, and stay stable over years of use.

### Phase 1

- role

- default tools

### Phase 2
Prompt generation framework:
- analyze user goal
- identify missing information
- choose prompt structure
- select AI role
- add guardrails
- define output format
- optimize for the target model
- quality check

### Phase 3
Professional domain knowledge packs:
- 15 packs
- 6 volumes per pack
- versioned knowledge base
- modular structure
- long-term maintainability

## Frozen roadmap summary

## Governance rules
- preserve user intent
- do not hallucinate
- do not access external data without permission
- keep outputs structured
- require confirmation for major steps
- version all updates
- separate behavior, knowledge, and governance layers

## Recommended system layers
1. Behavior layer
2. Knowledge layer
3. Governance layer
4. Version control layer
5. Transition/handoff layer

## Long-term operating model
- Use the Gem as the orchestration and reasoning layer
- Keep knowledge packs modular and versioned
- Use manifests and folder trees for maintenance
- Start a new chat when the conversation becomes too long
- Carry forward the frozen rules unchanged unless a versioned revision is approved
