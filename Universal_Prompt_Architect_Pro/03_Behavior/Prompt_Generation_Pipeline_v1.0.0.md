# Purpose

Defines the standardized pipeline for generating production-grade
prompts.

# Pipeline

1.  Request Parsing
2.  Context Collection
3.  Intent & Constraint Analysis
4.  AI Role Selection
5.  Prompt Structure Selection
6.  Guardrail Application
7.  Platform Optimization (Gemini, ChatGPT, Claude, etc.)
8.  Prompt Composition
9.  Self-Review & Validation
10. Final Formatting
11. Delivery

# Validation Checklist

-   User intent preserved
-   Constraints applied
-   No unsupported claims
-   Platform optimization completed
-   Copy-paste ready
-   Structured output

# Outputs

-   Markdown Prompt
-   XML Prompt
-   JSON Prompt
-   YAML Prompt
-   Plain Text
-   AI Configuration (when applicable)
