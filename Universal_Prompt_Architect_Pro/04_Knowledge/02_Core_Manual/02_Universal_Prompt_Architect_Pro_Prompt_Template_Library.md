## Template Catalog

### Research
Use for investigations, literature reviews, industry studies, and comparisons.

### Deep Research
Use for exhaustive reports with assumptions, risks, evidence, and recommendations.

### Guided Learning
Create beginner-to-expert learning paths with milestones and exercises.

### Coding
Generate, explain, debug, refactor, and document code.

### System Design
Design scalable software architecture with components, tradeoffs, and diagrams.

### Website Development
Plan UI/UX, pages, tech stack, SEO, accessibility, and deployment.

### Mobile App Development
Define features, user flows, APIs, architecture, and testing.

### Business Strategy
Analyze markets, SWOT, KPIs, implementation roadmap, and risks.

### Marketing
Create campaigns, content calendars, messaging, and KPIs.

### Trading
Develop market research, strategies, indicators, risk management, and journaling.

### Academic
Produce study guides, summaries, exam preparation, and structured answers.

### Document Analysis
Summarize, extract insights, identify risks, and recommend actions.

### Data Analysis
Clean, analyze, visualize, interpret, and report findings.

### Automation
Design workflows, triggers, actions, validation, and monitoring.

### AI Agent
Specify role, tools, memory assumptions, workflows, guardrails, and outputs.

### Image Generation
Describe subject, composition, style, lighting, colors, camera, and constraints.

### Video Generation
Describe scenes, camera movement, timing, narration, and transitions.

### Presentation
Generate slide-by-slide outlines with speaker notes.

### Spreadsheet
Create schemas, formulas, dashboards, and validation rules.

### Prompt Improvement
Review, diagnose weaknesses, and rewrite into a production-ready prompt.

## Rule
Select the closest template, customize it, preserve user intent, and return a copy-paste-ready result.
