# 📘 Prompt Engineering Master Knowledge Pack
## Volume 6 — Evaluation, Testing & Quality Assurance
**Version:** 1.0

# Purpose
Establish a repeatable process for evaluating, testing, validating, and continuously improving prompts.

---

# 1. Evaluation Framework

Evaluate every prompt for:
- Accuracy
- Completeness
- Clarity
- Relevance
- Consistency
- Robustness
- Reusability

---

# 2. Quality Rubric

Score each criterion from 1–5.

| Criterion | Description |
|-----------|-------------|
| Accuracy | Meets the requested objective correctly |
| Completeness | Covers all required aspects |
| Clarity | Easy to understand |
| Structure | Well organized |
| Reliability | Produces consistent results |
| Reusability | Easy to adapt |

---

# 3. Prompt Testing Workflow

1. Define success criteria.
2. Create representative test cases.
3. Execute the prompt.
4. Compare outputs with expectations.
5. Record observations.
6. Refine the prompt.
7. Retest.

---

# 4. Validation Checklist

Before approving a prompt:

- Objective is satisfied
- No conflicting instructions
- Appropriate level of detail
- Output format followed
- User intent preserved
- Errors identified and corrected

---

# 5. Failure Patterns

Common issues:
- Ambiguous wording
- Missing context
- Overly broad scope
- Conflicting constraints
- Undefined audience
- Unstructured outputs

---

# 6. Hallucination Risk Reduction

- State unknowns clearly.
- Avoid unsupported claims.
- Request citations when appropriate.
- Separate facts from assumptions.
- Encourage clarification if information is missing.

---

# 7. Regression Testing

When updating prompts:
- Compare with previous version.
- Verify existing capabilities remain intact.
- Document changes.
- Re-run representative tests.

---

# 8. Continuous Improvement

Feedback Loop:
Design → Test → Measure → Improve → Version → Deploy

Track:
- Successes
- Failures
- User feedback
- Edge cases
- Revisions

---

# 9. Version Management

Use semantic versioning:
- Major
- Minor
- Patch

Maintain a change log for every revision.

---

# 10. Final Release Checklist

✓ Objectives met
✓ Structure verified
✓ Constraints respected
✓ Formatting correct
✓ Reusable
✓ Maintainable
✓ Documented
