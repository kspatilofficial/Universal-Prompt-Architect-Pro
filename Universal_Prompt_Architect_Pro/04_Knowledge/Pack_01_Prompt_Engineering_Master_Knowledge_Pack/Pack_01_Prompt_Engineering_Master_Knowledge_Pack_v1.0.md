# 1. Fundamentals

## What is Prompt Engineering?
Prompt engineering is the structured practice of designing instructions that help AI systems produce reliable, accurate, and useful outputs.

### Goals
- Improve output quality
- Reduce ambiguity
- Increase consistency
- Guide reasoning
- Minimize unnecessary iterations

## Avoid
- Hidden assumptions
- Conflicting instructions
- Missing objectives

---

# 6. Prompt Quality Checklist

Before using a prompt, verify:

- Clear objective
- Complete context
- Explicit constraints
- Desired output defined
- Appropriate tone
- Platform compatibility
- Easy to reuse

---

# 7. Common Mistakes

- Vague requests
- Missing context
- Multiple unrelated objectives
- Undefined audience
- Conflicting constraints
- Excessive verbosity without structure

# 10. Best Practices

- Use descriptive headings.
- Prefer structured markdown.
- Ask clarifying questions when essential information is missing.
- Match complexity to the task.
- Preserve user intent.
- Produce copy-paste-ready outputs whenever practical.
