# Purpose
Optimize prompts for major AI platforms while preserving intent and output quality.

# Platform Optimization Framework

For every platform evaluate:

1. Strengths
2. Limitations
3. Ideal Use Cases
4. Prompt Style
5. Output Formatting
6. Tool Usage
7. Best Practices

---

# 1. Google Gemini

## Strengths
- Long-context reasoning
- Research assistance
- Multimodal understanding
- Google Workspace integration

## Best Practices
- Provide rich context.
- Use clear section headings.
- Request structured Markdown.
- Break large tasks into stages.

---

# 2. ChatGPT

## Strengths
- General reasoning
- Writing and editing
- Coding assistance
- Planning and ideation

## Best Practices
- Define role and objective.
- State constraints explicitly.
- Specify output format.
- Request validation when appropriate.

---

# 3. Claude

## Strengths
- Long-form writing
- Document analysis
- Careful explanations
- Constitutional reasoning

## Best Practices
- Provide complete context.
- Ask for organized documents.
- Prefer section-based outputs.

---

# 4. Microsoft Copilot

## Strengths
- Microsoft 365 integration
- Office productivity
- Enterprise workflows

## Best Practices
- Reference Word, Excel, Outlook, or PowerPoint tasks.
- Request business-ready outputs.

---

# 5. Perplexity

## Strengths
- Web research
- Source-backed answers
- Current information

## Best Practices
- Ask for citations.
- Request comparison of multiple sources.
- Separate facts from opinions.

---

# 6. Google AI Studio / APIs

## Strengths
- Prompt prototyping
- Model experimentation
- API workflows

## Best Practices
- Keep prompts modular.
- Separate system instructions from user inputs.
- Reuse prompt templates.

---

# Cross-Platform Prompt Rules

- Preserve user intent.
- Avoid platform-specific assumptions unless required.
- Use portable Markdown formatting.
- Prefer reusable prompt architecture.

---

# Platform Selection Guide

| Goal | Recommended Platform |
|------|----------------------|
| Deep research | Gemini / Perplexity |
| General writing | ChatGPT |
| Long documents | Claude |
| Microsoft productivity | Copilot |
| Prompt prototyping | Google AI Studio |
