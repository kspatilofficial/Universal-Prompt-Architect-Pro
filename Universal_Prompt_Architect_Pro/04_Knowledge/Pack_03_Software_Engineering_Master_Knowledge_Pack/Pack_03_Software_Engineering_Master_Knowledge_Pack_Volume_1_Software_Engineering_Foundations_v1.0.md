# 1. What is Software Engineering?

Software engineering is the disciplined approach to designing, building, testing, deploying, and maintaining software systems.

Goals:
- Reliability
- Maintainability
- Scalability
- Security
- Usability

---

# 2. Software Characteristics

High-quality software should be:
- Correct
- Efficient
- Secure
- Reliable
- Reusable
- Maintainable
- Portable
