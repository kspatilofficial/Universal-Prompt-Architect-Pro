# 🛡️ Cybersecurity, Networking & DevSecOps Master Knowledge Pack
## Volume 5 — Cloud Security, Monitoring & Incident Response
**Version:** 1.0

# Purpose
Introduce cloud security principles, operational monitoring, and incident response practices for modern cloud environments.

---

# 1. Cloud Security Fundamentals

Cloud security protects cloud-hosted applications, infrastructure, identities, and data.

Goals:
- Confidentiality
- Integrity
- Availability
- Compliance

---

# 2. Shared Responsibility Model

Security responsibilities are divided between the cloud provider and the customer.

Understand who secures:
- Infrastructure
- Operating systems
- Applications
- Data
- Identity

---

# 3. Cloud Identity & Access Management (IAM)

Core concepts:
- Users
- Roles
- Permissions
- Least privilege
- Multi-factor authentication

---

# 4. Network Security

Protect cloud networks using:
- Firewalls
- Security groups
- Network segmentation
- Private networking
- Zero Trust principles

---

# 5. Logging & Monitoring

Monitor:
- System logs
- Application logs
- Audit logs
- Metrics
- Alerts

---

# 6. SIEM

Security Information and Event Management (SIEM) centralizes security logs for detection, investigation, and response.

---

# 7. Incident Response

Typical phases:
- Preparation
- Detection
- Analysis
- Containment
- Eradication
- Recovery
- Lessons learned

---

# 8. Threat Intelligence

Use trusted intelligence sources to identify emerging threats and improve defenses.

---

# 9. Business Continuity & Disaster Recovery

Prepare for disruptions through:
- Backups
- Replication
- Recovery testing
- Recovery objectives

---

# 10. Best Practices

- Enable continuous monitoring
- Apply least privilege
- Encrypt sensitive data
- Patch systems promptly
- Test incident response plans
