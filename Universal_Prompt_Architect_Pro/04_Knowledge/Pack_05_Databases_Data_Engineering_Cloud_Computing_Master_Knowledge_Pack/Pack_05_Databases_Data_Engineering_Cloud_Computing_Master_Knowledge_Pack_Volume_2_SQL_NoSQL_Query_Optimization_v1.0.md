# 🗄️ Databases, Data Engineering & Cloud Computing Master Knowledge Pack
## Volume 2 — SQL, NoSQL & Query Optimization
**Version:** 1.0

# Purpose
Build practical knowledge of relational and non-relational databases, querying techniques, and database performance optimization.

---

# 1. SQL Fundamentals

SQL (Structured Query Language) is used to create, manage, and query relational databases.

Core operations:
- SELECT
- INSERT
- UPDATE
- DELETE

---

# 2. Query Structure

Essential clauses:
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- LIMIT

Write clear and efficient queries.

---

# 3. Joins & Relationships

Common joins:
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- CROSS JOIN

Use joins to combine related data.

---

# 4. Transactions & Concurrency

Transactions follow ACID principles.

Concurrency concepts:
- Locks
- Isolation levels
- Deadlocks
- Rollbacks

---

# 5. NoSQL Databases

Major models:
- Document
- Key-Value
- Column-Family
- Graph

Choose based on scalability, flexibility, and workload.

---

# 6. Query Optimization

Improve performance by:
- Reducing unnecessary scans
- Filtering early
- Selecting required columns only
- Optimizing joins

---

# 7. Indexing Strategies

Common indexes:
- B-Tree
- Hash
- Composite
- Unique
- Full-text

Balance read performance with write overhead.

---

# 8. Execution Plans

Execution plans show how a database processes queries.

Review plans to identify:
- Full table scans
- Expensive joins
- Missing indexes

---

# 9. Database Security

Best practices:
- Least privilege
- Parameterized queries
- Encryption
- Auditing
- Backup protection

---

# 10. SQL & NoSQL Best Practices

- Normalize when appropriate
- Denormalize only for justified performance gains
- Monitor query performance
- Maintain indexes
- Document schema changes
