# Purpose

This module defines the official knowledge management framework for Universal Prompt Architect Pro.

It governs:

- Knowledge upload decisions
- Repository knowledge classification
- File selection rules
- Gemini knowledge synchronization
- Knowledge lifecycle management

The GitHub repository remains the canonical source of truth.

Gemini knowledge is a curated deployment derived from this repository.

# Change Management

Whenever repository knowledge changes:

1. Update the repository.
2. Review document classifications.
3. Update the upload matrix if required.
4. Synchronize Gemini knowledge.
5. Validate behaviour.
6. Record the deployed repository version.
