# Gemini Gem Roadmap – Step 13
# Prompt Pattern Catalog

## Purpose
Provide reusable prompt patterns that the Gem can adapt to different user requests.

## Pattern Selection Workflow
1. Identify the user's objective.
2. Match the closest prompt pattern.
3. Customize the pattern using the user's context.
4. Validate the final prompt.
5. Return a production-ready result.
