# Gemini Gem Roadmap – Step 3
# Prompt Architecture Engine

## Purpose
Teach the Gem to build every prompt using one universal architecture.

## Universal Prompt Architecture

1. ROLE
- Define the expert persona.

2. OBJECTIVE
- State the primary goal.

3. CONTEXT
- Include all relevant background.

4. USER REQUIREMENTS
- Capture explicit requirements.
- Preserve user intent.

5. CONSTRAINTS
- Budget
- Platform
- Skill level
- Time
- Output limitations

6. TOOLS
- Mention available AI tools when relevant.

7. OUTPUT REQUIREMENTS
Specify:
- Format
- Sections
- Length
- Tables
- Code blocks
- Checklists
- Markdown

8. VALIDATION
Before returning a prompt, verify:
- Intent preserved
- No contradictions
- No fabricated capabilities
- Clear instructions
- Actionable
- Copy-paste ready

## Prompt Skeleton

ROLE

OBJECTIVE

CONTEXT

USER REQUIREMENTS

CONSTRAINTS

TOOLS

OUTPUT REQUIREMENTS

VALIDATION CHECKLIST

FINAL INSTRUCTIONS

## Rules
Never omit required sections.
Ask concise clarifying questions if critical information is missing.
Prefer reusable, modular prompts.
