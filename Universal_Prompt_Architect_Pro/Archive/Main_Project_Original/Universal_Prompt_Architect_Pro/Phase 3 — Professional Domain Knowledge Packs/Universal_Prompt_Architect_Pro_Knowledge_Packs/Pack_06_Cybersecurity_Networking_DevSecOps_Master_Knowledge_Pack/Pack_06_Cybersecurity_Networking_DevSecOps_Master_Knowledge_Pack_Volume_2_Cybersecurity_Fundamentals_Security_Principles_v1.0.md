# Purpose
Build a strong foundation in cybersecurity concepts, threats, defenses, governance, and security best practices.

---

# 1. Cybersecurity Fundamentals

Cybersecurity protects systems, networks, applications, and data from unauthorized access, attacks, and disruption.

Core objectives:
- Protect information
- Maintain trust
- Reduce risk

---

# 2. CIA Triad

The three core security principles:
- Confidentiality
- Integrity
- Availability

These guide security architecture and decision-making.

---

# 3. Threats, Vulnerabilities & Risks

Definitions:
- Threat: Potential cause of harm
- Vulnerability: Weakness that can be exploited
- Risk: Likelihood and impact of exploitation

---

# 4. Common Cyberattacks

Examples:
- Phishing
- Malware
- Ransomware
- DDoS
- SQL Injection
- Cross-Site Scripting (XSS)
- Insider threats

---

# 5. Security Controls

Categories:
- Preventive
- Detective
- Corrective
- Administrative
- Technical
- Physical

---

# 6. Defense in Depth

Use multiple layers of protection:
- Network
- Endpoint
- Application
- Identity
- Data
- Monitoring

---

# 7. Security Governance

Includes:
- Policies
- Standards
- Procedures
- Compliance
- Auditing

---

# 8. Risk Management

Process:
- Identify assets
- Assess threats
- Evaluate risks
- Mitigate
- Monitor continuously

---

# 9. Security Awareness

People are a key part of security.

Topics:
- Password hygiene
- Social engineering
- Safe browsing
- Email safety
- Reporting incidents

---

# 10. Cybersecurity Best Practices

- Least privilege
- Multi-factor authentication
- Regular patching
- Backups
- Continuous monitoring
- Incident response planning
