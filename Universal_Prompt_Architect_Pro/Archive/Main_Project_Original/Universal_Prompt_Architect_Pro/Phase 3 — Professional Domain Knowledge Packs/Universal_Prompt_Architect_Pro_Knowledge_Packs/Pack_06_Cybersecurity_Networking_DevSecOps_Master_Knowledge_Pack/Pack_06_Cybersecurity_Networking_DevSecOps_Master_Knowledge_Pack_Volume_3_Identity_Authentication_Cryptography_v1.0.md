# 🛡️ Cybersecurity, Networking & DevSecOps Master Knowledge Pack
## Volume 3 — Identity, Authentication & Cryptography
**Version:** 1.0

# Purpose
Provide a practical foundation for managing digital identities and protecting information using authentication and cryptography.

---

# 1. Identity & Access Management (IAM)

IAM manages digital identities and controls access to resources.

Core functions:
- Identity lifecycle
- Authentication
- Authorization
- Auditing

---

# 2. Authentication vs Authorization

Authentication verifies **who** a user is.

Authorization determines **what** that user can access.

---

# 3. Password Security

Best practices:
- Strong unique passwords
- Password managers
- Rotation where required
- Account lockout policies

---

# 4. Multi-Factor Authentication (MFA)

Combine two or more factors:
- Something you know
- Something you have
- Something you are

---

# 5. Single Sign-On (SSO)

SSO enables users to authenticate once and access multiple trusted applications.

Benefits:
- Better user experience
- Centralized identity management

---

# 6. Cryptography Fundamentals

Objectives:
- Confidentiality
- Integrity
- Authentication
- Non-repudiation

Types:
- Symmetric encryption
- Asymmetric encryption

---

# 7. Hashing & Digital Signatures

Hashing verifies integrity.

Digital signatures provide authenticity and integrity.

---

# 8. Public Key Infrastructure (PKI)

Components:
- Certificates
- Certificate Authorities
- Public keys
- Private keys

---

# 9. Certificate Management

Practices:
- Secure issuance
- Renewal
- Revocation
- Monitoring expiration

---

# 10. Best Practices

- Apply least privilege
- Enable MFA
- Protect private keys
- Rotate secrets
- Audit access regularly
