# Purpose
Provide a foundation in databases, data modeling, and data management concepts used in modern software systems.

---

# 1. What is a Database?

A database is an organized collection of data designed for efficient storage, retrieval, and management.

Goals:
- Reliability
- Consistency
- Availability
- Integrity

---

# 2. Types of Databases

Common categories:
- Relational (SQL)
- NoSQL
- Key-Value
- Document
- Graph
- Time-Series

---

# 3. Data Modeling

Core concepts:
- Entities
- Attributes
- Relationships
- Cardinality
- Constraints

A good model reflects business requirements.

---

# 4. Database Design

Design stages:
- Conceptual model
- Logical model
- Physical model

Normalize data where appropriate while balancing performance.

---

# 5. Keys & Relationships

Key types:
- Primary Key
- Foreign Key
- Composite Key
- Unique Key

Relationships:
- One-to-One
- One-to-Many
- Many-to-Many

---

# 6. Data Integrity

Maintain:
- Entity integrity
- Referential integrity
- Domain integrity

---

# 7. Transactions

ACID properties:
- Atomicity
- Consistency
- Isolation
- Durability

Transactions keep data reliable.

# 8. Indexing Basics

Indexes improve query performance.

Consider:
- Search patterns
- Write overhead
- Storage cost

# 9. Backup & Recovery

Practices:
- Regular backups
- Restore testing
- Disaster recovery planning
- Replication

# 10. Best Practices

- Design before implementation
- Document schemas
- Secure sensitive data
- Monitor database health
- Review performance regularly
