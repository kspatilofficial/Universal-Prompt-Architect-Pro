# Purpose
Provide a beginner-friendly foundation in cloud computing, cloud service models, deployment models, and modern cloud infrastructure.

---

# 1. What is Cloud Computing?

Cloud computing delivers computing resources over the internet on demand.

Benefits:
- Scalability
- Flexibility
- Cost efficiency
- High availability

---

# 2. Cloud Service Models

- IaaS (Infrastructure as a Service)
- PaaS (Platform as a Service)
- SaaS (Software as a Service)

Choose the model based on the level of control and responsibility required.

---

# 3. Deployment Models

Common deployment options:
- Public Cloud
- Private Cloud
- Hybrid Cloud
- Multi-Cloud

---

# 4. Core Cloud Services

- Compute
- Storage
- Networking
- Databases
- Identity & Access Management (IAM)

---

# 5. Virtualization & Containers

Virtualization allows multiple virtual machines on one physical server.

Containers package applications with their dependencies for consistent deployment.

# 7. Cost Optimization
