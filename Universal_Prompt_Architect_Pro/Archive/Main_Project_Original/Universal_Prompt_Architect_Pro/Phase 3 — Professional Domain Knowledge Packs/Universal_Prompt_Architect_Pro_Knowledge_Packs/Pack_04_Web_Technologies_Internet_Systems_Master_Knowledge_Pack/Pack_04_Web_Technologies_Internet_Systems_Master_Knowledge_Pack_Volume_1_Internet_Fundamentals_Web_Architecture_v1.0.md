# 🌐 Web Technologies & Internet Systems Master Knowledge Pack
## Volume 1 — Internet Fundamentals & Web Architecture
**Version:** 1.0

# Purpose
Provide a solid foundation in how the Internet and the World Wide Web work, including the technologies, protocols, and architecture behind modern web applications.

---

# 1. The Internet

The Internet is a global network of interconnected computers that communicate using standardized networking protocols.

Goals:
- Connectivity
- Communication
- Resource sharing
- Information exchange

---

# 2. The World Wide Web

The Web is a service that runs on the Internet, enabling users to access interconnected documents and applications through web browsers.

Core components:
- Browsers
- Web servers
- Websites
- Web applications

---

# 3. Client–Server Architecture

A typical web system consists of:

- Client (browser or app)
- Server (application)
- Database (persistent storage)

The client sends requests, and the server processes them and returns responses.

---

# 4. HTTP & HTTPS

HTTP is the protocol used for web communication.

HTTPS adds encryption using TLS to improve:
- Privacy
- Authentication
- Data integrity

Common methods:
- GET
- POST
- PUT
- PATCH
- DELETE

---

# 5. Domain Names & DNS

A domain name provides a human-readable address for a website.

DNS (Domain Name System) translates domain names into IP addresses.

---

# 6. IP Addresses & Networking Basics

Important concepts:
- IPv4
- IPv6
- Ports
- Routers
- Firewalls
- NAT

These enable devices to locate and communicate with one another.

---

# 7. Web Servers

Common responsibilities:
- Serve web pages
- Process requests
- Deliver static assets
- Run server-side applications
- Handle security and logging

---

# 8. Modern Web Architecture

Typical layers:
- Presentation Layer
- Application Layer
- Data Layer

Supporting services may include:
- Authentication
- APIs
- Caching
- Content Delivery Networks (CDNs)

---

# 9. Performance Fundamentals

Improve performance through:
- Caching
- Compression
- Efficient resource loading
- Optimized images
- CDN usage

---

# 10. Security Fundamentals

Core concepts:
- HTTPS
- Authentication
- Authorization
- Secure cookies
- Input validation
- Protection against common web attacks
