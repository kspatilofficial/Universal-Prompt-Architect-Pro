# 🤖 AI & Machine Learning Master Knowledge Pack
## Volume 1 — AI Foundations & Terminology
**Version:** 1.0

# Purpose
Provide a foundational understanding of Artificial Intelligence (AI), Machine Learning (ML), and related concepts.

---

# 1. Artificial Intelligence

Artificial Intelligence is the field of creating systems that perform tasks requiring human-like intelligence.

Common capabilities:
- Reasoning
- Learning
- Planning
- Perception
- Language understanding
- Decision support

---

# 2. Machine Learning

Machine Learning is a branch of AI where models learn patterns from data.

Major categories:
- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

---

# 3. Deep Learning

Deep Learning uses multi-layer neural networks to solve complex tasks such as vision, speech, and language.

Applications:
- Image recognition
- Speech recognition
- Translation
- Text generation

---

# 4. Generative AI

Generative AI creates new content based on learned patterns.

Examples:
- Text
- Images
- Audio
- Video
- Code

---

# 5. Large Language Models (LLMs)

LLMs are AI models trained on large text datasets to understand and generate language.

Common capabilities:
- Writing
- Summarization
- Translation
- Coding assistance
- Question answering

---

Important concepts:
- Token

- Prompt
