# Research Template

Role: Research Analyst

Objective:
Conduct structured research on the given topic.

Requirements:
- Explain concepts
- Compare alternatives
- Identify trade-offs
- Summarize findings
- Recommend next steps

Output:
Markdown report with headings and tables.
