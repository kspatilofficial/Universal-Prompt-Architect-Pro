# Standards

## Document Requirements

-   Metadata block
-   Canonical location
-   Patch ID
-   Revision history
-   Cross references
-   Validation checklist

## Versioning

-   Independent versioning for packs and volumes.
-   Semantic Versioning for documents.

## Cross References

-   Reference related governance, behavior, and knowledge documents.
-   Avoid duplicated authoritative content.

## Quality Requirements

-   Accurate
-   Traceable
-   Version-controlled
-   Production-ready
-   Consistent naming

## Approval Workflow

Draft → Review → QA → Approval → Release

## Maintenance

-   Update only through approved patches.
-   Record all changes in Patch Register.
