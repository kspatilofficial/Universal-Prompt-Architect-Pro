# Universal Prompt Architect Pro (UPAP)

> A production-grade, repository-driven framework for prompt engineering, AI runtime governance, knowledge management, and Gemini Gem development.

---

## Overview

Universal Prompt Architect Pro (UPAP) is a structured repository designed to support the design, governance, validation, maintenance, and deployment of production-quality AI prompt systems.

The repository serves as the canonical source for project documentation, runtime specifications, governance policies, behavioural rules, knowledge packs, deployment assets, release artefacts, and validation materials.

## Folder Overview

### 00_Project_Documentation

Project documentation, architecture references, roadmaps, and supporting documentation.

### 01_Runtime

Runtime architecture, AI operating systems, execution models, and runtime specifications.

### 02_Governance

Project governance, standards, naming conventions, version control, change management, and manifests.

### 03_Behavior

AI behaviour rules, reasoning workflows, quality assurance workflows, and prompt generation processes.

### 04_Knowledge

Knowledge base, manuals, reference material, and domain knowledge packs.

### 05_Deployment

Deployment assets and implementation resources.

### 06_Release

Release packages and versioned deliverables.

Repository validation, audits, certifications, and verification artefacts.

Historical and archived materials retained for reference.
