# Code of Conduct

## Universal Prompt Architect Pro (UPAP)

---

# Purpose

The Universal Prompt Architect Pro repository is maintained as a professional environment for developing, documenting, governing, validating, and deploying AI-related knowledge and engineering resources.

This Code of Conduct establishes the behavioural expectations for all contributors and participants.

---

# Our Principles

We aim to maintain a collaborative environment that values:

- Professionalism
- Respect
- Accuracy
- Transparency
- Constructive feedback
- Documentation quality
- Continuous improvement
- Responsible AI development

---

# Expected Behaviour

Contributors are expected to:

- Communicate respectfully.
- Provide constructive feedback.
- Support evidence-based discussions.
- Respect repository governance.
- Preserve repository integrity.
- Maintain documentation quality.
- Report issues responsibly.
- Collaborate in good faith.

---

# Unacceptable Behaviour

The following behaviours are not acceptable:

- Harassment or personal attacks.
- Discrimination or abusive language.
- Deliberate misinformation.
- Intentionally bypassing repository governance.
- Unauthorised structural modifications.
- Introducing fabricated or unverifiable technical information.
- Publishing confidential information without permission.
- Disruptive or intentionally misleading contributions.

---

# Repository Governance

All contributors are expected to respect the repository's governance policies.

Governance documentation located within:

```
02_Governance/
```

takes precedence over individual preferences when repository organisation or standards are involved.

---

# Documentation Standards

Contributors should:

- write clearly,
- maintain consistency,
- avoid unnecessary duplication,
- preserve canonical terminology,
- document significant changes appropriately.

---

# AI-Assisted Contributions

AI tools may be used to assist with documentation and development.

However, contributors remain responsible for:

- reviewing generated content,
- verifying technical accuracy,
- ensuring consistency with repository governance,
- avoiding fabricated information,
- maintaining repository quality.

AI-generated content must not be accepted without human review.

---

# Reporting Behaviour Concerns

If behaviour inconsistent with this Code of Conduct is identified, it should be reported privately to the repository maintainers.

Reports should include:

- a clear description of the concern,
- relevant context,
- supporting evidence where available.

All reports should be handled professionally and respectfully.

---

# Enforcement

Repository maintainers reserve the right to:

- request revisions,
- reject contributions,
- remove inappropriate content,
- restrict participation where necessary to protect repository integrity.

Enforcement decisions should be fair, consistent, and proportionate.

---

# Scope

This Code of Conduct applies to:

- repository discussions,
- issues,
- pull requests,
- documentation contributions,
- governance proposals,
- AI-assisted contributions,
- other project-related interactions.
